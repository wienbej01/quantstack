# GLOSSARY

- **Bars family**: A directory grouping bars by timeframe (e.g., `bars_1m`).
- **Canonical bars**: UTC ns timestamped OHLCV with fixed column names.
- **Checksum**: Hashes computed on in‑memory normalized inputs to ensure fair comparisons.
- **Additive Gold**: Gold allows derived fields but forbids resampling or shifting timestamps.
