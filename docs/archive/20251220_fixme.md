# 20251220 FixMe Sprint Plan: Regime Strategy Stabilization

## Mission
Restore correctness and production readiness for the regime-aligned strategy stack by fixing all identified defects (policy infrastructure, regime feature calculations, logging hygiene) while reinforcing automated quality controls. Target audience is a deterministic coding agent; every directive below must be followed precisely.

---

## Global Implementation Principles
- **Determinism & No Forward Look:** All feature calculations operate on data available up to bar `t`. Persist anchor values via backward-safe methods (e.g., `ffill`) but never peek ahead. Strategies must submit orders for execution on bar `t+1` only.
- **Schema Adherence:** Preserve types/names defined in `qx_core.schemas` (e.g., `RegimeSignal.segment`, `RegimeType`). Any new fields must be added via explicit schema updates with matching documentation.
- **Coding Standards:** Python 3.11 with Ruff style (100-char lines, explicit imports). New code must pass `make lint`, `make check-types`, and relevant pytest suites. Use docstrings and targeted inline comments sparingly for complex logic.
- **Logging Discipline:** Replace direct `print` calls with gated messaging behind a `verbose` flag; default behaviour must remain silent to protect batch pipelines and tests.
- **Testing Philosophy:** Every defect fix accompanies regression coverage. Tests must be deterministic (fixed seeds, synthetic data) and avoid wall-clock/timezone ambiguity beyond specified conversions.
- **Dependencies:** Prefer existing helpers (`qx_features.core_basics`) before introducing new utilities. Do not introduce third-party packages without approval.

## Workstream B – Regime Feature Correctness

### B1. Previous-Extreme AVWAP Persistence
- **Location:** `qx-features/src/qx_features/regime_enhanced.py`, function `_compute_prev_extreme_avwaps`.
- **Objective:** Anchor AVWAP at first touch of prior-session high/low and maintain value until invalidated, aligning with documentation.
- **Steps:**
  1. Replace current `np.where(..., group["close"])` fallback with logic storing AVWAP only when `touches_prev_high/low` true. Before first touch, keep NaN; after touch, `ffill` the computed AVWAP.
  2. Compute cumulative price * volume and volume only for bars after touch; use group-wise resets keyed by `(session_date, anchor_id)`.
  3. Ensure anchors reset each session; verify timezone conversions remain ET-based.
  4. Remove fallback to last close.
- **Quality Controls:** Add regression test verifying values remain constant post-touch and NaN before. Validate via `pytest tests/test_regime_enhanced_features.py::TestAnchoredVWAPFeatures::test_prev_extreme_persistence`.

### B2. ICT FVG Level Stability
- **Location:** `compute_ict_structures` in same file.
- **Objective:** Prevent NaNs and ensure FVG lower/upper bounds align with documented pattern (three-bar window) right from first detection.
- **Steps:**
  1. Use sliding window arrays to assign `lower`/`upper` without relying on `.shift(2)` on filtered rows (e.g., store high/low using `group['high'].shift(2)` on full index before masking).
  2. For the first detection, populate both bounds; ensure `ffill` maintains last active gap levels.
  3. Re-evaluate active flag conditions: active until price closes within gap; ensure boolean columns are cast to `bool` dtype.
- **Quality Controls:** Unit test verifying first FVG detection yields non-null levels and toggles to inactive when filled.

### B3. VPA Stopping Volume Robustness
- **Location:** `compute_order_flow_vpa` helper `is_stopping_volume`.
- **Objective:** Fix `int < DataFrame` comparison errors when `volume_spike` triggered.
- **Steps:**
  1. Refactor helper signature to accept `(group, idx, lookback)` or compute slice inline: `prev_rows = group.iloc[max(0, idx-lookback):idx]`.
  2. Guard case where `len(prev_rows) < lookback` – return `False`.
  3. Access `volume_spike.iloc[idx]` safely (already boolean).
  4. Maintain logic for trend reversal by summing close differences; ensure `.sum()` works even with `float`.
- **Quality Controls:** Add test with synthetic data causing volume spike on 4th bar verifying `f__vpa__stopping_volume` toggles and no exceptions raise.

### B4. Logging Hygiene
- **Location:** same module, `compute_intraday_volume_profile`, `compute_ict_structures`, `compute_order_flow_vpa`.
- **Objective:** Silence default execution unless `verbose=True` passed through config dict.
- **Steps:**
  1. Introduce local `logger` or simple `if cfg.get("verbose")` guard; pass `verbose` parameter from `compute_all_regime_enhanced_features` into subordinate functions (add optional `log=False` argument to each helper).
  2. Remove unconditional `print` statements; convert to conditional `print` or use `logging` module (module-level logger configured once).
- **Quality Controls:** Extend tests to capture stdout, ensuring no output when `verbose=False`; optionally assert output when forced true.
