Do **not** modify upstream `qx-*` core modules unless absolutely necessary; when interaction is required, invoke public APIs and extend via extension packages.
- **Infrastructure:** Python 3.11 with Ruff-managed style (100-character lines). Enforce deterministic formatting via `make format`, `make lint`, `make check-types`. Keep import ordering standard lib → third-party → local. Avoid duplicate module implementations; reuse upstream helpers where possible.
- **Data dependencies:** Real market data resides under `/home/jacobw/gcs-mount/gold/stocks/1m/<SYMBOL>/<YEAR>/<YEAR-MONTH>.parquet`. All tests must rely on this structure; synthetic data is forbidden in production paths.
- **Trading rules:** Signals generated on 10-minute cuts, executed on next 1-minute bar. Maximum one open position per symbol. All orders require SL=1% and TP=1.5R. Force flat by 15:59:59 ET (no overnight holds). No forward-looking leakage in features/labels; enforce cooldowns/time filters.
- **Strategy defaults:** Decision policy thresholds tuned for 3–5 trades/day. Regime detector uses moderated variance ratio (1.2/0.8) and ADX thresholds, with persistence cooldowns. Reporting must capture intraday SL/TP outcomes and gating rejections. Reference `docs/INTRA_ML_PIPELINE.md` and `docs/extensions/intraday_ml_models/BACKTEST_RUNBOOK.md` when validating policy/backtest wiring.
