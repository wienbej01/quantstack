# Phase A Pipeline Artifacts

This directory contains the artifacts generated by the Phase A intraday ML pipeline.

## Artifacts Description

- `manifest.json`: A JSON file containing the manifest for the dataset. It includes the symbols, date ranges, and other metadata for the data used in the experiment.
- `training_data.parquet`: A parquet file with the aligned training data, including features and labels.
- `model_lgbm/`: A directory containing the trained LightGBM model. The model is saved as `model.pkl`.
- `cv_report.json`: A JSON file with the cross-validation report, including metrics for each fold.
- `oos_features.parquet`: A parquet file with the out-of-sample features for the OOS period defined in the `splits` config.
- `oos_predictions.parquet`: A parquet file with the out-of-sample predictions from the trained model.
- `oos_orders.parquet`: A parquet file with the orders generated by the decision policy based on the OOS predictions.
- `oos_rejections.parquet`: A parquet file with the signals that were rejected by the decision policy and the reasons for rejection.
- `policy_config.json`: A JSON file with the configuration of the decision policy used to generate the orders.

## Reproducibility

To reproduce this experiment, you can use the `run_phaseA_pipeline.py` script with the same master configuration file and the same input data. The pipeline is designed to be deterministic, so running it with the same inputs should produce the same outputs.

### Checksums

To ensure the integrity of the input data, you can use checksums. The `inputs_checksum.json` file (not yet implemented) will contain the checksums of the input data files.
